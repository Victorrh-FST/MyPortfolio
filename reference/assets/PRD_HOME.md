# VICTOR'S PERSONAL PORTFOLIO

## Homepage PRD — Google Stitch Approved Design

### 1. Project objective

Build a responsive personal portfolio website presenting me as a UX Designer, Bubble Developer, and AI Engineer.

The homepage should communicate my professional capabilities, showcase selected projects, establish credibility, and encourage potential clients and employers to contact me.

**Primary headline:**

UX Designer | Bubble Developer | AI Engineer

**Supporting description:**

Designing and building modern web and mobile applications using Bubble.io, AI-assisted development, and modern programming technologies.

**Primary positioning:** A product designer and developer who can take ideas from product thinking and interface design through to functional application development.

### 2. Visual design reference

The supplied Google Stitch screenshot is the approved visual direction.

Reproduce its design faithfully.

Visual characteristics:

- Minimal, modern editorial style.
- Very light grey/off-white backgrounds.
- Black typography.
- Bright blue/purple accent colour for primary buttons.
- Rounded project cards.
- Generous whitespace.
- Soft grey card backgrounds.
- Subtle shadows and borders.
- Clear typography hierarchy.
- Simple navigation.
- Responsive two-column project grid.

Do not replace the design with a generic developer portfolio template.

Use the actual Stitch export, screenshots, components and design tokens wherever available.
